# /handoff — 引き継ぎ

## 出力（8 項目。省略不可）
```
1. 現状      : Phase / 次タスク / 実装解禁の可否
2. 作業      : このセッションで実行したタスク ID
3. 変更      : 変更したファイルと 1 行要約（git diff --stat を併記）
4. 実測      : 実行したコマンドと出力の所在（evidence/ の相対パス）
5. 判定と根拠: 工学判定語 + 根拠となる実測
6. 未解決    : OQ-ID / CONF-ID の一覧
7. 停止理由  : なぜここで止まるか（DEC-ID / ゲートの BLOCK 条件）
8. 必要な人間判断: DEC-ID と、決定しない場合に停止する作業
```

## 手順
1. 上記 8 項目を出力する。
2. `control/STATE.md` を更新する（Phase / 次タスク / 実装解禁 / 直近の実測 / 停止理由）。
3. `control/STATE.md` と `control/decisions.md` を commit する。

## 禁止
- 未実行を実行済みと書かない。
- 研究状態を会話にだけ残さない。`control/` に書く。
- 「あとは実行するだけ」と書かない。何が塞いでいるかを ID で書く。
