# /deviation — 逸脱の記録

## 記録する場面
- 原文の手順を実行できなかった。
- 代替手段で近似した（近似の度合いを数値で書く）。
- ツール・環境の制約で検証が不完全に終わった。

## 追記フォーマット（`control/deviations.md`）
```
| DEV-0NN | <UTC> | <対象> | <原文の要求> | <実際> | <理由> | <影響> | <是正> | OPEN |
```

## 規則
- 既存行を書き換えない。訂正は新しい行を追加する（SRC-01 SOV§1139）。
- 事後の正当化を書かない。`理由` は事実のみ。
- `影響` には、この逸脱が無効化する主張を明記する。

## 禁止
- 逸脱を記録せずに結果だけ残さない。記録のない結果は証拠として使えない。
