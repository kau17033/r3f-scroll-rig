# /decision — 人間判断の起案

## 起案する条件（CLAUDE.md §6）
研究目的・仮説・推定対象・指標・MDE・N・α・seed・除外・停止規則／モデル束縛／
`sources` `CLAUDE.md` `.claude` `control/AUTHORITY.md` の変更／
push・外部公開・有料 API・資格情報・不可逆操作。

## 起案フォーマット（`control/decisions.md` に追記）
```
| DEC-0NN | <決定すべき一文> | <CONF-ID または —> | <影響タスク> | PENDING |
```
本文末尾に次を併記する。
1. 選択肢 A / B（3 つ以上なら A / B / C）
2. 各選択肢の帰結（何が可能になり、何が不可逆になるか）
3. 決定しない場合に停止する作業の一覧
4. 判断に必要な情報のうち、こちらで取得できるもの／できないもの

## 禁止
- Status を自分で `APPROVED` にしない。変更は人間が commit する。
- 「おそらくこちらが妥当」で先に実装しない。起案して停止する。
- 決定待ちの間、依存しない作業は進める（全停止はしない）。
